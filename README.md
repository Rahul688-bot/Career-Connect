# CareerConnect – Student Placement Management System

## About the Project
CareerConnect is a web-based student placement management system designed to help students explore placement opportunities and help companies and administrators manage recruitment activities.

## Features
- Student registration and login
- Student dashboard
- Company dashboard
- Administrator dashboard
- Placement application management
- Database schema and initial data scripts

## Technologies Used
- **Backend:** Java, Spring Boot (verify against your actual implementation)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Build Tool:** Maven

## Project Structure
- `PlacementApplication.java` – Application entry point
- `PortalController.java` – Web controller
- `application.properties` – Application configuration
- `pom.xml` – Maven dependencies and build configuration
- `schema.sql` – Database schema
- `data.sql` – Initial database data
- HTML, CSS, and JavaScript files – User interface

## How to Run
1. Install Java and Maven.
2. Install and start MySQL.
3. Configure the database connection in `application.properties`.
4. Create or initialize the database using the provided SQL scripts.
5. Open a terminal in the project directory.
6. Run the application using `mvn spring-boot:run`.
7. Open the local URL configured for the application in your browser.
